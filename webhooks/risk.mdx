## Risk events

| Event                                 | Description                                                     |
| --------                              | -------------------------------------------------------         |
| `risk.alert`                          | Triggered when a risk alert is generated for a business.        |


## risk.alert
Below payload is dispatched whenever is generated for a business. This risk can be high, medium or low based on the decision matrix on worth score.  

```json
{
  "event_type": "risk.alert",
  "payload": {
    "business_id": "2f2616ae-d695-42c8-ba94-da023abee546",
    "business_name": "XYZ LTD.",
    "risk_level": "LOW | MODERATE | HIGH",
    "risk_alert_subtype": ""
  }
}
```
