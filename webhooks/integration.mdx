## Integration events

| Event                             | Description                                                                       |
| --------                          | -------------------------------------------------------                           |
| `integration.connected`           | Triggered when an integration is connected for a business.                        |
| `integration.disconnected`        | Triggered when an integration is disconnected for a business.                     |
| `integration.failed`              | Triggered when an integration fails for a business                                |


## integration.connected | integration.disconnected | integration.failed
Below payload is dispatched whenever an integration for a business is connected, disconnected or failed. 

```json
{
  "event_type": "integration.connected | integration.disconnected | integration.failed",
  "payload": {
    "business_id": "2f2616ae-d695-42c8-ba94-da023abee546",
    "business_name": "XYZ LTD.",
    "case_id": "bbde8bb6-316f-4121-ac77-f17c35a0e8ea",
    "integration_category": "Banking",
    "status": "CONNECTED | DISCONNECTED | FAILED"
  }
}
```
