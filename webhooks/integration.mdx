## Integtation events

| Event                             | Description                                                                       |
| --------                          | -------------------------------------------------------                           |
| `integration.added`               | Triggered when applicant (business) adds an integration.                          |
| `integration.removed`             | Triggered when applicant (business) removes an integration.                       |
| `integration.failed`              | Triggered when an integration fails.                                              |
