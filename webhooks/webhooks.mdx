## Example
Suppose you have subscribed to the `business.created` webhook event, you will receive a notification every time a new business is created.

## Webhook Vs API

APIs send you the data when you request it. For Webhooks, you do not need to make a request. You receive the data when it is available.

> ### Example
> If you need to know whether a Applicant has accepted the invitation using APIs, you need to keep polling every few seconds until applicant has accepted the invitation. However, if you are using Webhooks, you can configure a webhook event business.onboarded to receive notifications when a business has accepted invitation and onboarded.
